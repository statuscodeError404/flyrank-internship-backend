I built DevCamper, a RESTful backend API that enables users to create, manage, and discover bootcamps and courses. The platform allows users to share educational content, write reviews, and help others find learning opportunities. Built with Node.js, Express.js, and PostgreSQL, it includes authentication, authorization, CRUD operations, and a scalable API architecture.

To run ther server: npm run dev     

Swagger UI: http://localhost:5000/api-docs
